# projektR

Za biranje proizvoljne staze pokrece se custom_staza.py
Za biranje proizvoljne linije na stazi pokrece se custom_linija.py
Za segmentiranje staze pokreni segmentiranje.py. Potrebno je imati stazu sa sredisnjom linijom, nece raditi ako se zada proizvoljna linija. Poanta ovoga je pomocu segmenata odrediti liniju, unutar svakog segmenta jednu tocku koje ce se spojiti.
